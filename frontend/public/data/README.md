# Cartografía de Galicia

`galicia.geojson` incluye un recorte de Natural Earth 1:10m, versión 5.1.2, con capas de tierra, zonas urbanas, carreteras principales, ríos y divisiones administrativas. Se recortó a la ventana de −11,5° a −4,5° de longitud y 39,4° a 46,4° de latitud y se simplificó para servirlo como un único GeoJSON local. Se añadieron puntos de localidades con coordenadas aproximadas para las etiquetas.

Los datos de Natural Earth son de dominio público. Consulta la [fuente original](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson) y los [términos de uso](https://www.naturalearthdata.com/about/terms-of-use/).
